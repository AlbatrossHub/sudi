WhatsApp OTP Login

Passwordless login using phone number and WhatsApp OTP

This module introduces seamless passwordless authentication for Odoo e-commerce and portal websites. Users can securely log in using just their phone number. A dynamic One-Time Password (OTP) is sent directly to their WhatsApp, ensuring both convenience and security.

Key Features

  • WhatsApp Integration: Utilizes the official Meta WhatsApp API to send secure OTPs.
  • Auto-Registration: Automatically creates a guest partner and user account for new phone numbers.
  • Smart Country Code: Auto-detects the user's country code based on IP or Timezone for faster entry.
  • Native Bug Fix included: Includes a native Odoo bug fix that allows you to submit Meta authentication templates for approval directly from Odoo.
  • Security First: Internal employees are restricted to email/password, keeping your backend secure. OTPs expire in 5 minutes.

Data Privacy

Data Handling: This module securely transmits the user's phone number to the Meta WhatsApp API solely for the purpose of delivering the authentication OTP. No other personal data is transmitted to third-party services. For more details on how user data is handled, please review our Privacy Policy.
